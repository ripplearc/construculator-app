# Build Flavors

The app has three Android build flavors on the `env` dimension: `fishfood`,
`dogfood`, and `prod`. They differ only by `applicationId`:

| Flavor   | applicationId                            |
|----------|-------------------------------------------|
| fishfood | `com.ripplearc.construculator.fishfood`  |
| dogfood  | `com.ripplearc.construculator.dogfood`   |
| prod     | `com.ripplearc.construculator`           |

## How the flavors are defined

The flavor list lives in `pubspec.yaml` under the `flavorizr:` key and is
processed by the [`flutter_flavorizr`](https://pub.dev/packages/flutter_flavorizr)
dev dependency.

Running `dart run flutter_flavorizr -f` reads that config and writes
`android/app/flavorizr.gradle`. The last lines of `android/app/build.gradle`
apply that file:

```
// ----- BEGIN flavorDimensions (autogenerated by flutter_flavorizr) -----
apply from: "flavorizr.gradle"
// ----- END flavorDimensions (autogenerated by flutter_flavorizr) -----
```

The `instructions:` list in the `flavorizr:` config is limited to the two Android
gradle processors. The default `flutter_flavorizr` run also rewrites
`lib/main.dart` and generates Dart and iOS files, which we do not want.

## Do not hand-edit generated flavor files

`android/app/flavorizr.gradle` is generated. Do not edit it by hand. To change a
flavor, edit the `flavorizr:` block in `pubspec.yaml` and re-run
`dart run flutter_flavorizr -f`, then commit both files.

The generated `flavorizr.gradle` also declares a `string/app_name` resource per
flavor, set to the current launcher label `Construculator`. Nothing references
it: `android/app/src/main/AndroidManifest.xml` still uses the literal
`android:label="Construculator"`, so the displayed name is unchanged.

## Building a flavor

```
fvm flutter build apk --flavor fishfood --dart-define=ENVIRONMENT=dev
fvm flutter build apk --flavor dogfood  --dart-define=ENVIRONMENT=qa
fvm flutter build apk --flavor prod     --dart-define=ENVIRONMENT=prod
```

iOS flavors are not set up yet. That work is tracked in CA-1054 and CA-1055.
